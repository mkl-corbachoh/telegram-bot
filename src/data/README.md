# Carpeta `data`

Esta carpeta está destinada a almacenar los datos utilizados y generados por el bot de Telegram.

## Estructura de la carpeta

Actualmente, la estructura es la siguiente:

```
data/
└── reservas/
```

### Subcarpetas

- **reservas/**: Contiene los archivos pdf de las reservas realizadas para el viaje. 

## Descripción

En el futuro, esta carpeta podría incluir otras subcarpetas para almacenar diferentes tipos de datos, como registros de actividad, configuraciones globales o archivos temporales necesarios para el funcionamiento del bot.
